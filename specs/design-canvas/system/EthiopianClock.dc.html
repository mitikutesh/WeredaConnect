How the hours map

The Ethiopian hour is the 24-hour time minus six, counted from 1 to 12, with the part of the day always said.

Rules
  1. Never a bare hour. The part of the day is always shown, so 7:20 can't be mistaken for 07:20.
  2. Deadlines and arrival windows also show the 24-hour time in small text. An Amharic farmer and an English buyer on the phone can't be six hours apart.
  3. Tap any time to see it on the other clock.
  4. Push messages follow the same rule: the server's PushText uses the same formatter, with shared test cases.
  5. Only the display changes. The server keeps every time in UTC and computes deadlines exactly as it does now.
